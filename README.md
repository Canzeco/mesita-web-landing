# mesita-web-landing

Marketing site for Mesita — lives at [mesita.ai](https://mesita.ai).

Single-page Next.js 16 app (Tailwind v4 + shadcn primitives). The
consumer app lives at [consumer.mesita.ai](https://consumer.mesita.ai)
and the business surface at
[business.mesita.ai](https://business.mesita.ai); both are separate
deployments.

## Develop

```bash
pnpm install
pnpm dev
```

Deployed automatically by Vercel on push to `main`.
